# Aerodynamic Analysis of Dimpled Rocket Body

## Project Overview
This repository contains the engineering documentation, 2D technical drawings, and Computational Fluid Dynamics (CFD) simulation results for a dimpled rocket body. The objective of this project is to evaluate the aerodynamic performance, pressure distribution, and flow characteristics over a dimpled surface compared to a standard smooth body. 

## Material & Manufacturing Specifications
* **Part Name:** DIMPLED ROCKET
* **Material:** Al 6061 - T6
* **Protective Finish:** Anodizing
* **Edge Preparation:** Remove all burrs and sharp edges (Chamfer 0.5 X 45° R0.5 MAX)

## GD&T Standards
* **Standard:** ASME Y14.5-2018
* **General Tolerances:** 
  * X.X = ±0.5 mm
  * X.XX = ±0.1 mm
  * Angles = ±0.5°

## Simulation Assets
The CFD analysis was conducted using ANSYS Fluent to validate aerodynamic behavior. Included in this repository are the visual contour and streamline plots for pressure, velocity, specific dissipation rate, and eddy viscosity.
